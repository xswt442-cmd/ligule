## [0.0.4] - 2026-10-14

### 简体中文

- Desktop 改用 Electron，新增工作区选择和审批设置，并改进导出与会话切换时的安全处理。
- 提供 Windows x64 安装包和 Linux x64 AppImage、deb；macOS 不属于当前正式发行目标。

### English

- Desktop now uses Electron, adds workspace selection and approval settings, and improves export safety across session changes.
- Provides a Windows x64 installer and Linux x64 AppImage and deb packages; macOS is outside the current formal release targets.
