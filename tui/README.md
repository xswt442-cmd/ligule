```sh
npm install -g ligule
```

在项目目录运行 `ligule run "检查项目结构"` 执行单次任务；运行 `ligule` 打开交互式终端界面。CLI/TUI 需要 Node.js 24 或更新版本。

CLI/TUI 使用共享 Core，保留 CLI 参数、配置和会话格式。服务配置、凭据和工具权限见[使用手册](docs/guide.zh-CN.md)。
