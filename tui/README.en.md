```sh
npm install -g ligule
```

Run `ligule run "Review the project structure"` from a project directory for a one-off task, or run `ligule` to open the interactive terminal UI. CLI/TUI requires Node.js 24 or newer.

CLI/TUI uses the shared Core and preserves its CLI arguments, configuration, and session format. See the [user guide](docs/guide.en.md) for service setup, credentials, and tool permissions.
