# 术语表

[简体中文](GLOSSARY.zh-cn.md) · [English](GLOSSARY.en.md)

本文统一说明 ligule 当前行为中使用的术语。协议方法名、配置键和错误码保留代码中的拼写。

| English term | 中文术语 | 在 ligule 中的含义 |
|---|---|---|
| **Kernel** | **内核** | 注册工具、校验调用、应用审批策略、执行获准工具并记录结果的运行时。新建时工具注册表为空。 |
| **Host** | **宿主** | Node.js 进程，负责项目环境和打开的会话，并装配 Kernel、模型服务、审批策略、会话记录、扩展与客户端协议。 |
| **Adapter** | **适配器** | 面向一种界面的入口，将 Host 的行为交给用户。CLI、TUI 和桌面界面使用不同传输方式。 |
| **Plugin** | **插件** | 由 Host 装载的模块，可注册工具或提示片段，并返回清理动作。 |
| **Tool** | **工具** | 已注册、可由模型调用的操作，包含名称、说明、参数模式和实现。工具调用必须通过 Kernel 校验和审批。 |
| **Capability** | **能力** | 执行操作系统或环境相关工作的 Host 侧代码，例如路径解析、进程执行或网络访问。能力不一定是模型可调用工具。审批结果中的 `capability` 字段标记本次评估的操作。 |
| **Tool mode** | **工具模式** | 对已注册工具和提示片段的一种命名选择。模式控制提供给模型的工具清单，不授予审批权限。 |
| **Approval policy** | **审批策略** | 工具调用参数与目标检查之后应用的判定规则。结果可以允许、拒绝或询问用户；会话可以覆盖配置中的审批方式。 |
| **Approval mode** | **审批方式** | 用户选择的审批档位，例如逐次询问或自动判定。它是审批策略判定链使用的一项设置。 |
| **Workspace** | **工作区** | 已登记的真实目录，用于标识项目并作为新会话的默认位置。一个桌面窗口可以并行打开多个工作区。 |
| **Project root** | **项目根目录** | Host 项目环境所属目录，其配置、资源和会话归属于此处。它可以与工具访问边界不同。 |
| **Boundary** | **访问边界** | 文件工具能够访问的路径范围，不决定会话归属。 |
| **Session record** | **会话记录** | 追加式 JSONL 事件日志，是消息、工具结果、轮次状态和可恢复会话事实的来源。 |
| **Checkpoint** | **检查点** | 对一段会话记录生成并单独校验的摘要，可缩短模型投影，不能替代 JSONL 原始记录。 |
| **Spill file** | **旁路文件** | 保存超过行内大小限制的工具结果或摘要的附属文件。记录保留读取该文件所需的引用。 |
