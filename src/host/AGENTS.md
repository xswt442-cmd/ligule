# Host

本目录负责客户端协议、按行传输、会话所有权与 Markdown 导出。仓库根 [AGENTS.md](../../AGENTS.md) 同时适用。

## 结构与职责

- `protocol.js` 定义方法与参数，`connection.js` 传输请求、答复和通知，`host.js` 管理会话及项目环境，`export.ts` 提供两端共用的序列化器。
- 协议方法以 `METHODS` 为准。新增方法同时更新分发、客户端调用和实际协议检查；参数模式的子集校验不代替业务校验。
- Node 持有业务状态；传输适配器不决定模型、权限、会话位置或记录格式。

## 会话与项目

- 项目环境包含配置、提供方、规则、模式目录、扩展、MCP 和会话目录，按规范化工作区身份缓存。另一项目必须通过装载器取得自己的环境；不能借当前项目继续执行。
- `session.create`、`session.open` 可携带 `projectRoot`。不存在、非目录、不可读分别报告 `host_project_root_missing`、`host_project_root_not_directory`、`host_project_root_unreadable`。无装载器时报告 `host_project_root_unsupported`。
- 会话首行记录工作区身份及 `workspaceOrigin`。客户端明确选择写 `explicit`，使用默认写 `default`；恢复不改首行。创建和恢复登记工作区，失败须报告，读取不登记。
- 会话编号进入文件名之前必须校验，拒绝路径分隔符、冒号、NUL 和 `..`；缺少记录报告 `session_not_found`。
- 重复打开已持有会话是纯读。`session.close` 释放装配与记录锁，运行中须先取消；等待运行结束不能把运行失败误报为释放失败。最后一份会话关闭后可释放额外项目环境。

## 读取、分支与导出

- `session.read` 读取已打开会话，或它的 `<父编号>.sub-<序号>` 子任务记录。子任务记录不能作为主会话恢复。
- 分页使用事件序号 `before` 与数量 `limit`，返回 `endSeq`、`hasMore` 和从完整记录折出的 `label`。无效游标明确拒绝；溢出正文只为返回的页读取。
- `sessions.list` 与 `sessions.search` 负责发现历史；项目没有记录目录时返回空列表。配置中的会话目录覆盖保持有效。
- 会话级分支复制当前完整记录；指定 `at` 只接受 `status: completed` 的 `turn`。原记录不改，未知可忽略事件与字段原样复制，新首行保存来源。分支重建检查点，沿用溢出引用，共享项目文件，不执行 Git 操作。
- 导出目标来自用户保存操作，可位于项目外。Host 读取完整正文并导出主记录和子任务；每份结果分别返回，已有子任务目标不覆盖。取消保存对话框不算错误。
- `paths.list` 只列边界内普通文件，不跟随链接；跳过 `.git`、`node_modules`、`dist` 和会话目录。遍历预算或不可读目录通过 `stopped` 报告，不能把不完整结果说成没有匹配。

## 配置、模型与凭据

- `config.get` 逐项构造公开字段：四个单服务模型字段、经过验证的服务清单与默认选择、配置来源及版本、审批默认值与规则。不能交出整个配置快照或密钥原文。
- 读取可写两层只读取一次，值、来源和版本须同源。项目共享与命令行层使用装载快照。打开设置不改变运行状态。
- `config.set` 按字段白名单校验值；写入用户层或项目本地层，携带读取版本。高层覆盖写入时返回 `shadowed`；保存、采用和失败分别报告。
- 标量、服务清单和默认选择由配置编辑模块管理；规则表增改删须写当前持有规则的层。解析器定位跨度，持锁比较版本并原子替换，错误不覆盖原文。
- `model.select` 为一份会话选择服务与模型，写入可忽略的 `modelSelection` 事件；空闲立即采用，运行中轮后采用。恢复沿用该选择；默认值不覆盖单独选择的会话，同一服务参数变化按轮次边界采用。
- `status.get` 区分实际模型、选定模型和待生效模型及服务身份。循环、压缩和子任务在一轮内共用同一提供方；`turnContext` 记录实际生效参数，不记录密钥。
- `credentials.status` 只返回是否配置及来源，`credentials.set` 和 `credentials.delete` 操作系统凭据库。非空环境变量优先并拒绝修改该引用；Linux 指定 Secret Service，错误不能回退为明文或 keyutils。

## 偏好与交互

- `prefs.read` 返回 `{settings, version}`，仅缺文件使用空版本。`prefs.write` 交回完整 JSON 和版本，在跨进程锁内比较；坏文档、超限、过期写入均拒绝。草稿和队列不截断。
- 审批与结构化提问各有请求身份，并归属于自己的会话。切换界面不终结后台等待；回答只交原请求一次。取消和释放只处理所属会话，替换 Host 后旧请求全部失效。
- `question.request` 等待真实回答或取消，没有回答超时。交互客户端才装载提问工具，子任务不继承提问载体；答案不构成工具授权。
